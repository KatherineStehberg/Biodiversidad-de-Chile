# 08 — Appium

## Objetivo
Explorar la automatización de pruebas en dispositivos móviles o emuladores
como práctica del Módulo 9 del curso.

## Estado inicial
Pendiente. Appium no está instalado. Biodiversidad de Chile es una aplicación
web (Next.js), no una aplicación móvil nativa. Este módulo se desarrolla como
práctica independiente del pipeline principal del proyecto.

## Problema detectado
La aplicación no tiene una versión nativa iOS ni Android. Se debe definir el
alcance real de Appium en este contexto antes de instalar nada:

- **Opción A:** pruebas sobre el navegador Chrome en un emulador Android
  apuntando a `http://localhost:3000` (usando el driver `UiAutomator2` con Appium).
- **Opción B:** ejercicio documentado del módulo con una aplicación de
  demostración externa, sin modificar este repositorio.

## Decisión tomada
Pendiente. Requiere definición de alcance y aprobación antes de implementar.
